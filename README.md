
# Paradise Nursery

## Project Overview
Paradise Nursery is an online houseplant shopping application designed to help customers explore and purchase a variety of indoor plants.

## Project Features
- Browse different categories of houseplants.
- View plant names, images, and prices.
- Add plants to a shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- View the total cost of purchases.

## Technologies Used
- React
- JavaScript
- CSS
- Redux Toolkit

## Project Purpose
The purpose of Paradise Nursery is to provide customers with a simple and convenient online platform for discovering and purchasing houseplants.
